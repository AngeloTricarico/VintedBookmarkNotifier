Vinted Dashboard: Durata Suono Personalizzabile

Versione completa con campo numerico per impostare la durata del suono (standard 2 secondi), fallback HTML diretto senza errori API 404, codice vibrazione rimosso, tema sfondo nero #000000 e testo grigio.

Installazione

  1. Premi “Copia URL segnalibro”.
  2. Modifica il preferito sul browser sostituendo l'URL.
  3. Ricarica la pagina Vinted e clicca sul preferito.

Vinted Dashboard (Suono con durata)

Cosa cambia

  • Campo numerico "Suono (s)": aggiunto #vss per regolare i secondi di suono. Il valore predefinito è 2 secondi ed è salvato in memoria locale.
  • Durata effettiva Web Audio: l'inviluppo audio mantiene il gain a 0.95 e sfuma a zero esattamente al termine dei secondi specificati.
  • Solo HTML Diretto: rimosso l'endpoint JSON v2 che generava il 404; il catalogo viene letto direttamente via HTML.
  • Vibrazione rimossa: ripuliti tutti gli elementi e i listener relativi all'API aptica.
  • Sfondo Nero (#vdark): opzione per sfondo #000000 e testo grigio.
